# n8n AI Personal Assistant

An end-to-end AI agent automation workflow built in **n8n** designed to act as a personal productivity assistant.

## Features
* **Real-Time Q&A:** Searches the web in real time to answer questions across various topics.
* **Calendar Management:** Schedules, updates, and organizes meetings and events automatically.
* **Email Automation:** Reads incoming emails, generates concise summaries, and drafts/sends context-aware replies.
* **Task & To-Do Tracking:** Creates, updates, and manages daily task lists.
* **Expense & Budget Tracking:** Logs expenses, categorizes spending, and monitors personal budgets.

## Setup
1. Download the `.json` workflow file from this repository.
2. Open your **n8n** instance and create a new workflow.
3. Click the options menu (`...`) in the top right and select **Import from File**.
4. Configure your API credentials (LLM provider, Google Workspace/Email, Search API, and database/sheets) and activate the workflow.
